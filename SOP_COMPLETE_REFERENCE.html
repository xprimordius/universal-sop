📊 Token System (F10)

SP.3TTE — Token Threshold EnginePer-Output
Purpose
Mathematical fuel budget so sessions don't crash mid-task. Math-based, not judgment.
ThresholdRange /200KAction
GREEN<108KFull operations, all SubSOPs active
YELLOW108–130KAbbreviated validation, plan checkpoint
RED130–141KCheckpoint NOW, no new deliverables
CRITICAL>141K (theoretical)Emergency dump (design says unreachable)

Emergency reserve = ~59K (never burned). RED(130K)+reserve(59K)=189K < 200K, so CRITICAL is unreachable by design.

Companion LTM (Live Token Monitor) after every section.

Doesn't scale: hardcoded 108K/130K assume a 200K window; the tight loop uses a model-aware [WINDOW] (200K or 1M) with no reserve restated. On a 1M model these numbers are meaningless.
