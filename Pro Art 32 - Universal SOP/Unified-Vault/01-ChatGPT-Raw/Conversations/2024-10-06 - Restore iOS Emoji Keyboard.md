# Restore iOS Emoji Keyboard

---

## 👤 You

How to change the iOS emoji keyboard back to normal? It is 4 deep now on 18 vs 5 befoe

---

## 🤖 ChatGPT

To change the iOS emoji keyboard layout back to normal (5 rows deep instead of 4), follow these steps:

1. **Close any open apps**: Exit any app where you're using the keyboard.
2. **Restart your device**: This sometimes resets minor issues with the keyboard.
3. **Check iOS version**: Go to **Settings > General > Software Update** and make sure you're running the latest iOS version, as this could be a bug related to the version you have.
4. **Reset Keyboard Settings**: You can reset the keyboard settings by going to **Settings > General > Reset > Reset Keyboard Dictionary**. This won't remove emojis but may restore the default layout.

If the issue persists, it could be related to a recent iOS update or an app that adjusts the keyboard behavior. Keep an eye out for iOS patches.
