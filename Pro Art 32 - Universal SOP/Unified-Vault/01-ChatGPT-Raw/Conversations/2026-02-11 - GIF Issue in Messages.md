## 🤖 ChatGPT

This is almost always an **iPhone settings + keyboard issue**, not your phone being broken.

### The common reasons (and fixes)
**1) #images is missing or removed**
- Open **Messages** → open any text thread  
- Tap the **“+”** button (or App Store icon) next to the text field  
- Look for **#images**
- If it’s not there → scroll down → **Edit** → turn **#images ON**

**2) iMessage is OFF**
- Go to **Settings → Messages**
- Make sure **iMessage = ON**
- GIFs via #images don’t work with SMS/MMS (green bubbles)

**3) Keyboard issue**
- Go to **Settings → General → Keyboard**
- Make sure **Emoji Keyboard** is added
- Restart Messages after adding

**4) Screen Time restriction (very common)**
- **Settings → Screen Time → Content & Privacy Restrictions**
- Tap **Allowed Apps**
- Make sure **iMessage** and **App Store** are allowed
- Also check **Content Restrictions → Web Content** (set to *Unrestricted* or *Allowed Websites*)

**5) Region / language glitch**
- **Settings → General → Language & Region**
- Region should be **United States**
- Restart after changing (even if it already says US)

**6) App cache bug**
- Force close Messages
- Restart iPhone
- If still missing: toggle **iMessage OFF → restart → ON**

### Quick test
- Open a message → type **“funny”** → tap **#images**
- If nothing appears, it’s either **Screen Time** or **#images disabled**
