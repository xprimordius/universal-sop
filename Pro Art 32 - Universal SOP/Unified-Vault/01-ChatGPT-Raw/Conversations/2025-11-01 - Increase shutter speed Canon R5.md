Here’s how to increase shutter speed when shooting **4K 120 fps** on the **Canon R5 Mark II**:  

---

### ⚙️ Step-by-Step
1. **Set to Manual or Shutter Priority Mode**
   - Turn the **Mode Dial** to **M** (Manual) or **Tv** (Shutter Priority).  
   - In **Auto or Scene modes**, shutter speed is locked.

2. **Enter Movie Mode**
   - Flip the **photo/video switch** near the viewfinder to the **movie camera icon**.  
   - Confirm top LCD shows **4K 120 fps**.

3. **Unlock Shutter Control**
   - Press the **Q** button → highlight the **shutter speed** box → use the **main dial** (top front dial) to adjust.  
   - If it’s **grayed out**, disable **Auto Shutter** or switch **shutter speed → manual** in the **Shoot Menu Tab → Movie Rec Quality** submenu.

4. **Adjust Exposure Manually**
   - Use the **top dial** to raise the speed (e.g., from 1/125 → 1/250 → 1/500 → 1/1000).  
   - For cinematic motion blur, use the **180-degree rule**:  
     → Shutter ≈ 1 / (2 × frame rate) → for 120 fps, about **1/240 s**.  
     → Faster (e.g., 1/500 s or 1/1000 s) = crisp motion; slower = blurrier.

5. **Disable Auto ISO/Shutter Lock if Needed**
   - Menu → **Shoot Tab 1 → ISO speed settings → ISO Auto limit/manual ISO**.  
   - Menu → **Movie Servo AF** → ensure not locking exposure.

---

### 🧠 Quick Tip
If you still can’t change it, check:
- **Exposure Mode:** must be Manual or Tv.
- **Shutter Angle Mode:** if using angle mode, change to “Shutter Speed” under **Menu → Movie Rec → Shutter mode**.
- **Electronic Shutter (High Speed Mode)** may limit adjustment when using some Canon Log or HDR modes—switch to standard.
