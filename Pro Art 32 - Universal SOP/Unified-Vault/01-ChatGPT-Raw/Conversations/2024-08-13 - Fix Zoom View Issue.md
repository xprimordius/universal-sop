# Fix Zoom View Issue

---

## 👤 You

zoom top right selection to change side by side gallery view not showing. how to fix? it's locked on single speaker view on desktop

---

## 🤖 ChatGPT

If you're unable to change the view from single speaker to side-by-side gallery view in Zoom on your desktop, there are a few potential solutions to fix the issue:

1. **Update Zoom:**
   - Ensure that you have the latest version of Zoom installed. Outdated versions may have limited functionality or bugs.
   - To update, open Zoom, click on your profile picture in the top right corner, and select "Check for Updates."

2. **Enable Gallery View:**
   - Make sure that you are not in "Fullscreen" mode. Exit fullscreen and check if the "Gallery View" option appears in the top right corner.
   - If you still don't see it, try resizing the Zoom window. Sometimes the view options appear only when the window is a certain size.

3. **Meeting Settings:**
   - If you're the host, check the meeting settings to ensure that gallery view is enabled. Sometimes, settings may restrict participants' view options.
   - Go to "Settings" > "In Meeting (Basic)" and ensure that "Gallery View" is toggled on.

4. **Video Settings:**
   - Go to "Settings" in the Zoom app and click on "Video." Ensure that all settings are correctly configured for your camera and display.
   - You can also try toggling between "HD" and "Standard Definition" to see if this triggers the view options to appear.

5. **Switch View Shortcut:**
   - You can try switching the view manually using the shortcut `Alt + F1` (Windows) or `Command + Shift + W` (Mac) to toggle between different views.

6. **Zoom Reset:**
   - If all else fails, sign out of Zoom, close the application, and restart your computer. Then, log back in and check if the gallery view option is available.

If none of these steps work, consider reinstalling the Zoom application as a last resort, which can resolve any software issues that might be causing the problem.
