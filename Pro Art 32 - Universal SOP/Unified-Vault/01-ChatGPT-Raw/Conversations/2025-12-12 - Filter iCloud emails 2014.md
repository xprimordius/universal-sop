## 🤖 ChatGPT

Got you. Here’s how to **see/filter only old iCloud emails (like from 2014)** depending on where you’re checking mail.

---

## 1. On iPhone / iPad (Mail app with iCloud account)

You *can’t* set a permanent “rule” on iPhone, but you can **filter + search by year**:

1. Open **Mail** → go to your **iCloud inbox** (or “All Inboxes” if needed).
2. Pull down a bit to show the **search bar**.
3. Type something like:  
   `2014`  
   Then tap **“Filter by date”** if it appears (on newer iOS), or:
4. Try: `date:2014` or `2014 from:someone@example.com` (search is a bit dumb, but this can surface 2014 emails).
5. You can also scroll down and use **“Filter”** (bottom-left in inbox) to narrow to:
   - Unread / Flagged / To: Me, etc.  
   Then manually scroll to the 2014 section.

> iOS Mail doesn’t have a strict “between Jan 1–Dec 31, 2014” filter, so it’s mostly **search + scrolling**.

---

## 2. On Mac (Mail app with iCloud account)

This is cleaner:

1. Open **Mail** on Mac.
2. In the sidebar, click your **iCloud inbox**.
3. In the **search bar** (top-right), type:  
   `date:2014`
4. Then click the **“+”** button under the search bar to add conditions:
   - Change the first drop-down to **“Date Received”**
   - Set it to **“is between”**
   - Choose **01/01/2014** and **12/31/2014**
5. Now you see only emails from 2014.  
   You can **select all → move** to a folder like “iCloud 2014” if you want a permanent bucket.

---

## 3. On iCloud.com (web browser)

1. Go to **iCloud.com** → sign in → open **Mail**.
2. Click the **search bar** at the top.
3. Type something like: `2014` or `before:2015` (web search is limited; it’s mostly keyword/date-text style).
4. Manually scroll until you’re in 2014 and, if you want:
   - Select those messages
   - Move to a folder named **“2014”** for easier filtering later.

---

## 4. If you mean “auto-filter everything from 2014 into a folder”

You *can’t retroactively* filter by date with rules, but you can:

1. On **Mac Mail**:
   - **Mailbox → New Smart Mailbox…**
   - Condition:  
     - **Date Received** → **is between** → `01/01/2014` and `12/31/2014`
   - Name it **“iCloud 2014”**.
2. This Smart Mailbox will **always show only 2014 messages** from your iCloud account.

Here’s how to filter **only 2014 emails in Gmail** — simple and exact:

---

### 🔹 **Search Filter for 2014**
Paste this into the Gmail search bar:

```
after:2013/12/31 before:2015/01/01
```

✅ This shows **all emails received in 2014** (Jan 1 – Dec 31).  
You can narrow it further, e.g.:

- From a person:  
  `after:2013/12/31 before:2015/01/01 from:example@gmail.com`
- With attachments:  
  `after:2013/12/31 before:2015/01/01 has:attachment`
- With a subject keyword:  
  `after:2013/12/31 before:2015/01/01 subject:invoice`

---

5. Click **“Create filter.”**
