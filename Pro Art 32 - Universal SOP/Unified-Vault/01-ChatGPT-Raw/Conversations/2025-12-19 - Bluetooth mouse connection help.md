## **Windows 10 / 11 (Keyboard-Only)**
1. **Open Settings:** `Windows + I`  
2. **Go to Bluetooth:**  
   - Press `Tab` until left menu is focused  
   - Use `Arrow keys` → select **Bluetooth & devices** → `Enter`
3. **Turn Bluetooth ON:**  
   - `Tab` until Bluetooth toggle → `Space`
4. **Add mouse:**  
   - `Tab` to **Add device** → `Enter`  
   - Select **Bluetooth** → `Enter`
5. **Put mouse in pairing mode** → use `Arrow keys` → select mouse → `Enter`

**Fast shortcut (often works):**  
`Windows + A` → `Tab` → toggle **Bluetooth** → `Enter`

---

## **macOS (Keyboard-Only)**
1. **Open System Settings:** `Command + Space` → type *System Settings* → `Enter`
2. **Bluetooth:**  
   - `Tab` / `Arrow keys` → select **Bluetooth** → `Enter`
3. **Turn Bluetooth ON:** `Tab` → toggle → `Space`
4. **Pair mouse:**  
   - Put mouse in pairing mode  
   - `Tab` to device list → select mouse → `Enter` → **Connect**

---

## **Emergency Fallback**
- **Plug mouse in with USB** (many Bluetooth mice work wired temporarily)
- **Use phone as a mouse** (Remote Mouse / Unified Remote)
