# Dual Bind Scroll Wheel

---

## 👤 You

how to dual bind scroll wheel up on a razer mouse to also pressing W simultaneously to scrolling up

---

## 🤖 ChatGPT

To dual bind the scroll wheel up on a Razer mouse to also press the "W" key simultaneously, you can use the Razer Synapse software. Here’s a step-by-step guide to achieving this:

### Step 1: Open Razer Synapse
1. Launch the Razer Synapse software on your computer.

### Step 2: Select Your Mouse
1. In Razer Synapse, select the Razer mouse you want to configure.

### Step 3: Configure the Scroll Wheel Up
1. Go to the "Customize" tab.
2. Locate the "Scroll Up" function on the mouse button layout.

### Step 4: Add a Secondary Function (Hypershift)
1. **Option 1: Using Hypershift**
   - Click on the scroll wheel up button.
   - Choose "Hypershift" and assign it to "W" (you might have to define what Hypershift is if not already configured).
   - Hypershift allows for a secondary function, so when you scroll up, it will also press "W".
   
2. **Option 2: Use Macros (Recommended)**
   - Go to the "Macro" tab on the top.
   - Click "Create Macro" and name it something like "ScrollUp_W".
   - Record a new macro by clicking "Record".
   - While recording, press "W" and then scroll up.
   - Stop recording and save the macro.
   - Go back to the "Customize" tab.
   - Click on the scroll wheel up function and select "Macro".
   - Choose the "ScrollUp_W" macro you just created.
   - Ensure it’s set to play "once" when you scroll up.

### Step 5: Test the Binding
1. After setting up the macro or Hypershift, test it in a game or application to ensure it works as expected.
2. Adjust any settings in Synapse if needed for the timing or behavior.

This setup should allow you to scroll up with the mouse wheel while simultaneously pressing the "W" key.

If you don't see the "Macro" tab directly in Razer Synapse, follow these steps to access and create a macro:

### Step 1: Open Razer Synapse
1. Open the Razer Synapse software on your computer.

### Step 2: Go to the Macros Module
1. If the "Macro" tab isn't visible, you may need to enable the Macros module.
2. Look for the "Modules" button on the dashboard or in the main menu. Click on it.

### Step 3: Install the Macros Module
1. In the Modules window, you should see a list of available modules.
2. Find the "Macros" module and click "Add" or "Install."
3. Once installed, the Macros tab will appear in the Synapse software.

### Step 4: Create a Macro
1. Click on the "Macro" tab that appears after installation.
2. Here, you can create a new macro, as described in the previous steps.

### Step 5: Assign the Macro to Scroll Up
1. After creating your macro, return to the "Customize" tab.
2. Assign the newly created macro to the scroll wheel up function.

If you still can’t find the Macro option, ensure your Razer Synapse software is up to date by checking for updates in the settings menu.
