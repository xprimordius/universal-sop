# Why you don’t see it on your amendment form
The **Articles Amendment form only edits the original article fields**:

```
Registered Office
Registered Agent
Mailing Address
```

The **Principal Executive Office Address is stored separately** in the entity record.

---

# How to set the principal address
After the LLC exists, you update it through:

```
File → Annual Renewal / Update Business Information
```

That screen includes:

```
Principal Executive Office Address
```

That is the address banks usually see.

---

# What you should do now

Follow the SOS instructions:

1. Remove **lines 5 and 6**
2. Keep **7 (mailing address)**
3. Leave **8 blank** or write:

```
Update business mailing address only.
```

Then after it processes:

```
File Annual Renewal → set Principal Executive Office Address
```

to:

```
2909 Wayzata Blvd Ste 1017
Minneapolis MN 55405
```

---

# Result

Your public record will show:

```
Registered Office
Registered Agents Inc
Owatonna MN
```

```
Principal Executive Office Address
2909 Wayzata Blvd Ste 1017
Minneapolis MN
```
