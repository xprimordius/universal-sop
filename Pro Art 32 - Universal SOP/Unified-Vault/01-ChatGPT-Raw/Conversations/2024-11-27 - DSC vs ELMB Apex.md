## 🤖 ChatGPT

To enable **10-bit color** on your ASUS ROG Swift 31.5" 4K 240Hz monitor, follow these steps:

### 1. **Check Graphics Card Support**
   - Ensure your GPU supports **10-bit color output** at your desired resolution and refresh rate.
   - Most modern GPUs from NVIDIA (GeForce 10 series or newer) and AMD (RX series or newer) support 10-bit color, but bandwidth may limit this at 4K 240Hz.

---

### 2. **Use the Right Connection**
   - Use **DisplayPort 1.4** or **HDMI 2.1** cables, as these are required for 4K at high refresh rates and 10-bit color.
   - Ensure your cable is certified to handle high bandwidth.

---

### 3. **Enable DSC (Display Stream Compression)**
   - If you are running at 4K 240Hz, **DSC** (Display Stream Compression) is often required to enable 10-bit color due to bandwidth limitations.
   - Enable DSC via the monitor's **On-Screen Display (OSD)** menu.

---

### 4. **Update Windows Display Settings**
   - Right-click on the desktop and select **Display settings**.
   - Scroll to **Advanced display settings** and ensure your resolution is set to **3840x2160** (4K) and refresh rate to **240Hz**.
   - Click **Display adapter properties** → Navigate to the **Monitor** tab and ensure the refresh rate matches your desired setting.

---

### 5. **Configure 10-bit in Graphics Control Panel**
   #### **For NVIDIA GPUs**:
   - Open the **NVIDIA Control Panel**.
   - Navigate to **Change Resolution** under the **Display** section.
   - Select your monitor, set:
     - Resolution: 3840x2160.
     - Refresh Rate: 240Hz.
     - Output Color Depth: **10 bpc**.
     - Output Color Format: **RGB or YCbCr 4:2:2/4:4:4**.
     - Output Dynamic Range: **Full**.
   - Apply changes.

   #### **For AMD GPUs**:
   - Open the **AMD Radeon Software** or **Adrenalin Software**.
   - Navigate to **Display Settings** → Enable **10-bit Pixel Format**.
   - Set resolution and refresh rate to the desired values.

---

### 6. **Check and Adjust In-Game Settings**
   - In competitive games like Apex Legends, ensure the game is optimized for HDR or 10-bit color if applicable.
   - Note that enabling 10-bit color with high refresh rates might introduce a slight performance trade-off in some scenarios.

---

### 7. **Monitor OSD Confirmation**
   - Access your monitor's **On-Screen Display (OSD)** menu to confirm that it displays **10-bit color** and your desired resolution and refresh rate.

---

If you experience issues such as lower refresh rates or color banding after switching to 10-bit, try adjusting the color format (e.g., RGB vs. YCbCr) or refresh rate (e.g., lowering to 144Hz).

## 🤖 ChatGPT

Apex Legends defaulting to low graphic settings could be caused by a few underlying issues. Here are potential causes and solutions:

---

### **1. Config File Settings Reset**
Apex Legends uses a configuration file (`videoconfig.txt`) to store graphic settings. If this file is corrupted or lacks proper permissions, the game may reset to defaults.

- **Solution:**
  1. Navigate to:
     - **Windows**: `C:\Users\<YourUsername>\Saved Games\Respawn\Apex\local\`
  2. Locate `videoconfig.txt`.
  3. Right-click → **Properties** → Ensure the file is not marked **Read-only**.
  4. Edit the file with a text editor to set your desired graphic settings manually.
  5. Save the changes and set the file to **Read-only** to prevent resets.

---

### **2. Driver or Hardware Detection Issues**
The game may fail to detect your GPU correctly due to outdated or misconfigured drivers.

- **Solution:**
  - Update your GPU drivers:
    - For NVIDIA: Use **GeForce Experience** or download from [NVIDIA's website](https://www.nvidia.com/Download/index.aspx).
    - For AMD: Use **Adrenalin Software** or download from [AMD's website](https://www.amd.com/en/support).
  - Reinstall the GPU driver using a **clean install** option.

---

### **3. Launch Options Conflicts**
Custom launch options or parameters could interfere with graphic settings.

- **Solution:**
  1. Open **Steam/Origin/EA App** → Right-click on **Apex Legends** → Select **Properties**.
  2. In the **Launch Options/Command Line Arguments** section, remove any conflicting commands.
     - Ensure there are no commands like `+mat_compressedtextures`, `+fps_max`, or other performance parameters.

---

### **4. Game File Corruption**
If key game files are missing or corrupted, Apex Legends may revert to default settings.

- **Solution:**
  1. Verify game files:
     - **Steam**:
       - Go to **Library** → Right-click **Apex Legends** → Select **Properties** → Navigate to **Local Files** → Click **Verify Integrity of Game Files**.
     - **Origin/EA App**:
       - Find **Apex Legends** → Click **Repair**.
  2. Reinstall the game if verification doesn’t resolve the issue.

---

### **5. Windows or System-Level Settings**
Windows or GPU settings may limit the game’s ability to apply higher-quality graphics.

- **Solution:**
  - Check your **Power Plan**:
    - Go to **Control Panel** → **Power Options** → Select **High Performance**.
  - Ensure GPU is set for high performance:
    - **NVIDIA Control Panel** → **Manage 3D Settings** → Add **Apex Legends** → Set **Power Management Mode** to **Prefer Maximum Performance**.
    - **AMD Radeon Settings** → Set **Performance Mode** for Apex Legends.

---

### **6. GPU or System Resource Issues**
The game might automatically lower settings if it detects insufficient resources.

- **Solution:**
  - Check if other programs are consuming resources during gameplay (use **Task Manager**).
  - Close unnecessary background applications to free up system resources.

---

### **7. Account Cloud Sync Issues**
Cloud synchronization might override your local settings.

- **Solution:**
  1. Disable cloud synchronization:
     - For **Steam**: **Library** → Right-click **Apex Legends** → **Properties** → **General** → Uncheck **Keep games saves in the Steam Cloud**.
  2. Delete `videoconfig.txt` and allow the game to recreate it after launch.

---

### **Test Each Solution**
After applying a fix, launch the game to see if it resolves the issue. If the problem persists, you might need to combine fixes (e.g., updating drivers and adjusting config files).
