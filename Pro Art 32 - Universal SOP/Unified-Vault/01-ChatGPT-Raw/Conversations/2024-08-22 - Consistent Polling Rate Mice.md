how to disable usb power saving windows

## 🤖 ChatGPT

Disabling USB power saving in Windows can help ensure that your USB devices, such as a gaming mouse, maintain consistent performance without interruptions caused by power-saving features. Here's how you can disable USB power saving:

### Method 1: Disable USB Selective Suspend via Power Options
1. **Open Control Panel:**
   - Press `Win + X` and select **Control Panel**.
   - Alternatively, you can search for "Control Panel" in the Start menu.

2. **Navigate to Power Options:**
   - Go to **Hardware and Sound** > **Power Options**.
   - Click on **Change plan settings** next to your active power plan.

3. **Change Advanced Power Settings:**
   - Click on **Change advanced power settings**.
   - In the **Power Options** dialog, expand the **USB settings** section.

4. **Disable USB Selective Suspend:**
   - Expand **USB selective suspend setting**.
   - Set both **On battery** and **Plugged in** to **Disabled**.

5. **Apply and Save Changes:**
   - Click **Apply** and then **OK** to save the changes.

### Method 2: Disable USB Root Hub Power Management
1. **Open Device Manager:**
   - Press `Win + X` and select **Device Manager**.
   - Alternatively, you can search for "Device Manager" in the Start menu.

2. **Locate USB Root Hub:**
   - Scroll down and expand the **Universal Serial Bus controllers** section.
   - Look for entries named **USB Root Hub** (there might be more than one).

3. **Disable Power Management:**
   - Right-click on a **USB Root Hub** entry and select **Properties**.
   - Go to the **Power Management** tab.
   - Uncheck the option **Allow the computer to turn off this device to save power**.
   - Click **OK**.

4. **Repeat for All USB Root Hubs:**
   - If there are multiple USB Root Hub entries, repeat the steps above for each one.

### Method 3: Disable USB Power Management via Registry (Advanced)
**Note:** Editing the registry can have significant effects on your system. Make sure to back up the registry before making changes.

1. **Open the Registry Editor:**
   - Press `Win + R`, type `regedit`, and press Enter.

2. **Navigate to USB Settings:**
   - Go to the following path:
     ```
     HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\USB
     ```
   - If the **USB** key doesn’t exist, you can create it.

3. **Create or Modify Entry:**
   - Right-click in the right pane, select **New > DWORD (32-bit) Value**.
   - Name it `DisableSelectiveSuspend`.
   - Double-click the entry and set the value to `1`.

4. **Restart Your Computer:**
   - Restart your computer to apply the changes.

These steps should help disable USB power-saving features, ensuring that your USB devices, such as your gaming mouse, perform consistently without interruptions.
