**How to Get Your Own Custom Clan or Discord Tag (Step-by-Step)**

### ✅ For a **Custom Discord Tag** (e.g., `Name#0001`)

> **Note:** Discord no longer uses 4-digit tags for most users unless you have **Nitro**.

#### Option 1: With Discord Nitro
1. **Subscribe to Nitro**
2. Go to **User Settings → My Account**
3. Click **Edit** beside your username.
4. Set your desired name and tag (if still available, e.g., `User#7777`)
5. Save changes — you can now customize the tag.

#### Option 2: Without Nitro (New Username System)
- You now choose a **unique handle** (like `@username`)
- No tags — only one global username per person
- **Custom tags are no longer editable without Nitro**

---

### ✅ For a **Custom Clan Tag** (for games or communities)

#### Option 1: Manual Tag in Usernames or Nicknames
- Set a consistent tag like `[PRSM] Alan` or `Alan | PRSM`
- Works across Discord servers or in-game lobbies
- Standardize with your team/community

#### Option 2: Use a **Bot to Auto-Assign Roles/Tags**
- Set up a **bot** like `Dyno`, `Carl`, or `MEE6`
- Auto-assign roles based on member tags or applications
- Display clan tags in role colors or side labels

#### Option 3: In-Game Clan Systems
- Games like **Call of Duty, Fortnite, Apex** allow clan tags
- Go to the game’s **Clan/Club settings**
- Create your clan and assign a **4–5 character tag**

---

### ✅ Bonus: Brand Your Tag Across Platforms
- Reserve matching **@handles** on Discord, TikTok, Instagram, Steam, Epic, etc.
- Use [Namecheckr](https://namecheckr.com/) to check availability

Got it. You're referring to the **custom server link/tag** (aka **Server Invite Splash Tag**) that shows up under **Boosts** — the one users can **tap and it links directly to your server** (like `discord.gg/yourtag`).

---

### ✅ How to Get a Custom Discord Server Tag (e.g., `discord.gg/yourname`)

This is called a **Vanity URL**, and it's only available if your server meets the **Boost level requirement**.

---

### 🔒 **Requirements**  
To unlock a **custom invite link** (`discord.gg/yourtag`), your server must:

- Be **boosted to Level 3**  
  - This requires **14 server boosts**

---

### 🎯 Steps to Set Your Custom Server Tag

1. **Boost to Level 3**
   - Either get 14 members to boost, or boost it yourself with multiple Nitro accounts

2. Go to **Server Settings → Custom Invite Link**
   - Only visible once you're Level 3

3. Click **Edit**, then enter your desired tag  
   - Example: `discord.gg/prsm`

4. Save changes — now this tag is clickable from Boost info and shareable

---

### 🔁 Tips
- Your custom tag must be **unique and available**
- You can change it anytime while at Level 3
- If your server **drops below 14 boosts**, you’ll **lose** the vanity URL
