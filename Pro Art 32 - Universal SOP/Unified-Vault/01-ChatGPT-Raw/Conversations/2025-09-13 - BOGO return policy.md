## 🤖 ChatGPT

It depends on the store’s policy, but here’s how it usually works:

- **BOGO is treated as a bundle.**  
  Both items are tied together for the discount. If you return one, the store often recalculates the purchase as if you had only bought the other item at full price.

- **Example:**  
  Buy 1 shirt at $50, get 1 free.  
  If you return the “free” one, you usually get **$0 back**.  
  If you return the one you paid for, the store may deduct the value of the free item, so you only get **$25 back** (because they’ll treat it like both were $25 each).

- **Some stores split the discount.**  
  Instead of one free, each item is rung up at 50% off. In that case, returning one just gives you back the discounted price.

👉 Bottom line: You don’t usually get to keep the free item *and* get full money back. Stores either refund the discounted price or require you to return both.
