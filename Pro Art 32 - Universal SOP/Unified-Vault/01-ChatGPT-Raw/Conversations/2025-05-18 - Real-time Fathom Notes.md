## 🤖 ChatGPT

Fathom AI currently **does not display real-time transcript notes in `.txt` format** while recording a meeting. However, here’s what you *can* do during a recording to see live notes or captions:

### ✅ Live Options During a Meeting:
1. **Live Transcript (Zoom + Fathom Integration Only)**:
   - Fathom provides **real-time captions** during Zoom calls (if enabled).
   - These appear as **highlighted snippets** in the Fathom sidebar or popup window (inside Zoom).
   - You can click and tag highlights (e.g., "Follow-up," "Action Item") during the call.

2. **Live Summary Panel (Fathom App)**:
   - If using the **Fathom desktop app**, it shows key takeaways live in the sidebar.
   - You can mark moments during the call; these are timestamped and transcribed after the call ends.

3. **Manual Workaround**:
   - If you need real-time `.txt` visibility:
     - Use **Zoom’s live transcription** feature or **Otter.ai live notes** in parallel.
     - Then manually save/export the text from there.

---

### 🛑 Limitations:
- **Fathom only outputs `.txt` after the call ends.**
- There is **no native way** to export or display a live `.txt` transcript mid-call.
