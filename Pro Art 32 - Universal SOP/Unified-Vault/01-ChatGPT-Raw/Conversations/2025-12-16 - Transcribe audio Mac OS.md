## 🤖 ChatGPT

**Fast, Free Transcription on macOS (Best Options)**

### ⚡ Fastest (Built-in)
**Mac Dictation**
- System Settings → Keyboard → Dictation → ON  
- Play audio/video near mic → real-time text  
- ✅ Free, instant  
- ❌ Less accurate, no timestamps

---

### 🎯 Best Accuracy (Free)
**Whisper (OpenAI) – Local**
- Install: `brew install whisper`  
- Run: `whisper audio.mp3 --model small`  
- ✅ Very accurate, private, supports many formats  
- ❌ Terminal required

---

### 🖱️ Easiest No-Code (Free Tier)
**OpenAI Whisper Web / Free Tools**
- **whisper-webui (local UI)**  
- **HuggingFace Whisper demo**  
- Upload file → text  
- ✅ Simple, accurate  
- ❌ File size limits

---

### 🧠 Apple Native (Hidden Gem)
**Voice Memos → Transcribe**
- Record/import audio in Voice Memos  
- macOS auto-transcribes  
- ✅ Free, native  
- ❌ Limited formatting

---

### 🧩 Bonus (If you already use it)
**CapCut Desktop**
- Import video → Auto Captions → Export text  
- ✅ Free, fast for video  
- ❌ Less clean text output

---

**My recommendation (TLDR):**
- **Pure speed:** Mac Dictation  
- **Best quality free:** Whisper (local)  
- **No setup:** Voice Memos or Whisper web

If you want **timestamps, speaker labels, or batch files**, say the word.

## 🤖 ChatGPT

**You’re one command away. Install the correct package.**

### ✅ Do this (official, best accuracy)
```bash
brew install openai-whisper
```

Verify:
```bash
whisper --help
```

Transcribe:
```bash
whisper youraudio.mp3
```

With timestamps + better accuracy:
```bash
whisper youraudio.mp3 --model medium --language en --verbose False
```

---

### ⚡ Faster / lighter (CPU-optimized)
```bash
brew install whisper-cpp
```

Transcribe:
```bash
whisper-cpp -f youraudio.mp3
```

---

### 🖥️ No Terminal (Free GUI)
If you want **click → upload → text**:
```bash
brew install --cask macwhisper
```
(Open app → drop file → export text)

- **Power user / accuracy:** `openai-whisper`
- **Speed / low CPU:** `whisper-cpp`
- **Zero friction:** `MacWhisper` (GUI)

## Why this happened (up-to-date explanation)
Recent Homebrew `openai-whisper`:
- Runs inside a **Python venv**
- If `--output_dir` is not set, output can land in:
  - The **current working directory**
  - Or the **process launch directory**
  - Or silently fail to write where you expect due to sandboxed permissions

This is **not** user error. It’s a known behavior change.

---

## One-command “never fail again” alias (recommended)
Add this once:

```bash
echo 'alias whisperx="whisper --output_dir ~/Downloads --verbose False"' >> ~/.zshrc
source ~/.zshrc
```

Now you can just run:
```bash
whisperx yourfile.mp3
```

Outputs will **always** land in Downloads.
