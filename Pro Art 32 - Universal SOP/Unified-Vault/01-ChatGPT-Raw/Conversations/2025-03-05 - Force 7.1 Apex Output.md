If Apex Legends previously recognized your earbuds as supporting **7.1 surround sound** but now only detects **stereo** after the latest update, follow these steps to **force 7.1 output**:

### **1. Check Windows Audio Settings**
1. **Right-click** the **speaker icon** in the taskbar → **Sound settings**.
2. Scroll down to **Advanced sound options** → **App volume and device preferences**.
3. Ensure Apex Legends is using the correct **output device** (your earbuds).
4. Go back to **Sound settings** → Click **your earbuds** under **Output device**.
5. Click **Spatial Sound** → Select **Windows Sonic for Headphones** (if supported) or **Dolby Atmos for Headphones** (if available).

### **2. Enable 7.1 Virtual Surround in Windows**
1. **Right-click** the speaker icon → **Sounds**.
2. Go to the **Playback** tab → Select your **earbuds**.
3. Click **Properties** → Navigate to the **Enhancements** tab.
4. **Enable "Virtual Surround" or "7.1 Virtual Speaker"** if available.
5. Go to the **Advanced** tab → Change the format to **24-bit, 48000 Hz (Studio Quality)**.
6. Click **Apply** and **OK**.

### **3. Verify Apex Legends Audio Settings**
1. Launch **Apex Legends** → Go to **Settings** → **Audio**.
2. Look for an **option to enable surround sound** (if available).
3. Restart the game and check if it detects **7.1 output**.

### **4. Force 7.1 Output Using Third-Party Software**
- **Dolby Atmos for Headphones** (Windows Store) – Paid but improves 7.1 emulation.
- **Razer Surround Sound** – Free software that virtualizes 7.1 audio.
- **Equalizer APO + HeSuVi** – Advanced software to emulate 7.1 audio.

### **5. Check Apex Legends Config File**
1. **Go to Apex Legends Config Folder**:  
   ```
   C:\Users\YourUsername\Saved Games\Respawn\Apex
   ```
2. Look for **"settings.cfg"** and open it with Notepad.
3. Find or add the line:
   ```
   sound.num_speakers 7
   ```
4. Save changes and restart the game.

### **6. Check Realtek Audio Drivers**
1. **Open Realtek Audio Console** (if installed).
2. Ensure **7.1 Surround** is enabled.
3. If using **USB or Bluetooth earbuds**, update your **Realtek/Audio Drivers**:
   - Open **Device Manager** (`Win + X → Device Manager`).
   - Expand **Sound, video, and game controllers**.
   - Right-click your audio driver → **Update Driver**.

If none of these work, Apex Legends may have removed **7.1 support for certain devices** in the latest update. In that case, forcing virtual surround via **Windows Sonic, Dolby Atmos, or HeSuVi** is your best bet.
