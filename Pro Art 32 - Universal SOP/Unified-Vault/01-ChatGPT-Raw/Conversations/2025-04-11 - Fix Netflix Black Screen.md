## 🤖 ChatGPT

Fix for Netflix Black Screen on Discord (Edge Browser):

### Cause:  
Netflix blocks screen sharing DRM content (HDCP) → black screen when streaming.

---

### Solution (Edge Specific):

#### 1. Turn Off Hardware Acceleration
- Edge Settings →  
- Search "Hardware Acceleration" →  
- Toggle Off → Restart Edge  

Path:  
`Settings` → `System and Performance` → Disable `Use hardware acceleration when available`

---

#### 2. Stream via Windowed Mode  
- Don't stream the whole screen.  
- In Discord → `Share Screen` → Select only Edge Netflix window (Not Entire Screen)

---

#### 3. Disable Browser Extensions
- Disable Adblockers / Privacy Extensions (Optional but can interfere)

---

#### 4. Use Browser Source Workaround
Alternative: Use Firefox or Chrome (same steps) — sometimes works better for streaming DRM content.

---

#### 5. Use Netflix App (Windows)
Download from Microsoft Store → Stream via Window Capture (Discord)  
Less DRM enforcement.

---

Final Recommendation:  
> Best consistency = Edge (Hardware Acceleration Off) + Window Capture + Low Res Streaming Settings (720p / 30fps)
