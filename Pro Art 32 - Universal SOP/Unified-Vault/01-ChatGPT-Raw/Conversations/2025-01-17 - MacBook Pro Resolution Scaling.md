## 🤖 ChatGPT

The confusion arises because macOS uses **scaled resolutions** by default to balance sharpness and UI size, rather than the native resolution of the display. Here’s the breakdown:

### Native Display Resolution:
- The 16" MacBook Pro M2 Max has a **Liquid Retina XDR display** with a **native resolution of 3456 x 2234** at 254 pixels per inch (ppi).

### Why the Default Resolution is Lower:
- macOS runs the display at a **scaled resolution** by default (e.g., 1728 x 1117 or 2056 x 1329) to optimize for **UI size, readability, and performance** while maintaining Retina sharpness.
- These are **logical resolutions**—the display actually renders at 2x or 3x the scaled resolution internally and then downsamples for sharpness.

### Scaled Resolution Options:
- **1728 x 1117 (Default):** Prioritizes readability with larger UI elements.
- **2056 x 1329 (Max Available in Settings):** Provides more screen real estate with smaller UI elements but keeps Retina-quality sharpness.

### Using Full Native Resolution:
To utilize the full **3456 x 2234** native resolution:
1. **Enable "More Space" Mode:**
   - Go to **System Settings > Displays** and select a higher scaling option like 2056 x 1329.
2. **Third-Party Tools:**
   - Use apps like [**BetterDisplay**](https://github.com/waydabber/BetterDisplay) to unlock and use the full native resolution or custom resolutions.

> **Note:** Running the display at native resolution makes UI elements very small, as macOS does not automatically scale UI elements at full resolution. This might not be practical for everyday use.
