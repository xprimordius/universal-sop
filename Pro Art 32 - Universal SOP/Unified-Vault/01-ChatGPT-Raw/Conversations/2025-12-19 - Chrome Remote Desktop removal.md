## Chrome Remote Desktop — What It Is & How to Remove It

### What it is
- **Chrome Remote Desktop (CRD)** lets you **access this computer remotely** from another device.
- The **service runs in the background** so remote access works even when Chrome is closed.
- If you **never set up remote access**, it’s safe to remove.

---

### Remove it (Windows)

**Option A — Full uninstall (recommended)**
1. **Settings → Apps → Installed apps**
2. Search **Chrome Remote Desktop**
3. **Uninstall**

**Option B — Stop the background service**
1. **Win + R →** `services.msc`
2. Find **Chrome Remote Desktop Service**
3. **Stop**
4. Set **Startup type → Disabled**

**Option C — From Chrome**
1. Go to **chrome://apps**
2. Right-click **Chrome Remote Desktop → Remove from Chrome**

---

### Mac (if applicable)
1. **System Settings → General → Login Items**
2. Remove **Chrome Remote Desktop**
3. **Applications → Chrome Remote Desktop → Uninstall**
   - Or run the included **Uninstall Chrome Remote Desktop** app

---

### Is it safe?
- **Yes**, it’s a legitimate Google service.
- **Remove it** if you don’t need remote access.
- **Keep it** only if you intentionally use remote desktop.
