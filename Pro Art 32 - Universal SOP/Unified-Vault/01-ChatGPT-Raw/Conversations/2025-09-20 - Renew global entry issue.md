---

## 🤖 ChatGPT

Here’s the fix:  

**1. Global Entry vs. SENTRI**  
- **Global Entry** = expedited re-entry to the U.S. from abroad + TSA PreCheck.  
- **SENTRI** = land border crossing program with Mexico (not needed if you only want Global Entry).  

**2. Why It Shows SENTRI**  
- The CBP Trusted Traveler Program (TTP) site manages *all* memberships (Global Entry, NEXUS, SENTRI).  
- If you accidentally clicked into SENTRI, it may show “applied for SENTRI” even if you only want Global Entry.  

**3. What To Do**  
- Log into your **TTP account** at: [ttp.dhs.gov](https://ttp.dhs.gov).  
- Under **“Programs”**, confirm which program you’re renewing.  
- If it shows **SENTRI application in progress**, cancel/withdraw that application.  
- Then select **Global Entry → Renew Membership**.  

**4. Important**  
- You cannot “convert” a SENTRI application into a Global Entry renewal. You must start the renewal for Global Entry specifically.  
- Renewal cost: $100 (covers 5 years, includes TSA PreCheck).  
- Do this ASAP, because SENTRI applications take longer and don’t substitute for Global Entry.
