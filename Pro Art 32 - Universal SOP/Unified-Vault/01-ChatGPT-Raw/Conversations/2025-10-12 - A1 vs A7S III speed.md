## 1. What “speed increase” might mean

“Speed” could refer to several metrics. Useful ones:

- **Max frame rate** (fps) at a given resolution  
- **Sensor readout speed / rolling shutter / blackout / latency**  
- **Bitrate / codec throughput**  
- **Write speed / data pipeline (cards, bus, buffer)**  

To claim “50% faster,” you must pick a definition (e.g. fps, or readout) and compare apples to apples (same resolution, crop mode, codec, etc.).

## 3. How to *test for a 50% improvement* yourself / in specs

1. **Pick the same resolution + codec.** For example, compare both in 4K 60 or 120 fps, with same compression (e.g. ALL-I or GOP).

2. **Compare frame rates:**  
   - If A7S III handles 60 fps, then 50% more would be 90 fps.  
   - If A1 only does 120 fps max in that mode, that’s only 100% more than 60, but spec may limit it.  

3. **Compare readout / latency / blackout.** Use test charts (moving lines) to see banding or skew. Use manufacturer spec “sensor readout time” where available.

4. **Compare bitrate / throughput.** If one supports much higher bitrate in same mode, that can reflect “speed.”

5. **Sustained thermal headroom.** If one can sustain recording 60 min vs 30 min, that’s an operational “speed” gain.

6. **Benchmark tests / real world video comparisons.** Side by side in identical settings.
