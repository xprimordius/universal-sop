## 🤖 ChatGPT

Acrobat (free/Reader version) can’t permanently change PDF metadata like the author. That’s why it’s still showing "Canva" even if you "save as PDF."  

### How to fix (free methods):
1. **Use a metadata editor:**
   - [PDF Candy (online)](https://pdfcandy.com/edit-pdf-metadata.html)
   - [Sejda Metadata Editor](https://www.sejda.com/edit-pdf-metadata)
   - Upload your PDF → change "Author" field → save.

2. **If you have Acrobat Pro:**  
   - Open PDF → `File > Properties` → `Description` tab → edit Author → `OK` → save.

3. **On Windows only:**  
   - Right‑click PDF → `Properties` → `Details` → edit "Author" (if unlocked).

4. **Mac Preview workaround:**  
   - Preview → `File > Export as PDF` → check if metadata clears. (Doesn't always allow editing.)

> The free Acrobat Reader simply doesn’t have this feature; you must use an online editor or Pro.

## 👤 You

is it sketchy if the meta data is removed?

---

## 🤖 ChatGPT

No, it's **not sketchy by itself**. Many companies and professionals remove metadata for privacy.  

### Why it’s normal:  
- Metadata often contains **irrelevant info** (software used, usernames, timestamps).  
- Lawyers, designers, and businesses routinely strip metadata before sharing files to prevent data leaks.  
- Most recipients **never check metadata**; they care about the visible content.  

### When it could raise eyebrows:  
- If the document is part of **legal evidence** and metadata is required, removing it could look like tampering.  
- If someone expects to verify document origin (e.g., official records).  

### Best practice:  
If you just want to hide “Canva” or “PDF Candy,” **clear only the author field** or leave metadata blank—this is 100% fine for resumes, proposals, or client docs.
