## 👤 You

Can you return Nike stuff from main store to outlet?

---

## 🤖 ChatGPT

### TLDR: Usually **NO**

**Nike Factory/Outlet** and **Nike Retail (Full-Price)** run different return systems.

**Rules that typically apply:**
- Items bought at **Nike.com or a full-price Nike store** must be returned to **full-price** Nike.
- Items bought from a **Nike Factory/Outlet** must be returned to an **outlet**.
- Receipts are required to route it correctly.

**Rare exception**
If the outlet manager approves as a courtesy (not guaranteed). Stronger chance if:
- The item is still sold at outlets
- You’re within the return window
- Tag + receipt present

**Best move**
Return to the same type of store where the purchase was made.

If you want, I can call the exact location (or check web/store policy listings) and confirm for you based on where you bought it.
