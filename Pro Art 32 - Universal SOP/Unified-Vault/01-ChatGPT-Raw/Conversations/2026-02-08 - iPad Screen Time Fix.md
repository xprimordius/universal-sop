## 🤖 ChatGPT

**Fast Fix — iPad stuck on Screen Time / Parental Controls**

### Try in this order (top → bottom):

#### 1) **Hard restart (most common fix)**
- **Face ID iPad:** Press **Vol Up → Vol Down → hold Power** until Apple logo.
- **Home button iPad:** Hold **Home + Power** until Apple logo.

---

#### 2) **Turn off Screen Time (if you know the passcode)**
- **Settings → Screen Time → Turn Off Screen Time**
- If it asks for a **Screen Time passcode** (not device passcode), enter it.

---

#### 3) **If Screen Time is locked / passcode forgotten**
You must **remove it via the organizer Apple ID**:

- **Settings → Screen Time → [Child’s Name]**
- Sign in with the **parent/organizer Apple ID**
- **Turn Off Screen Time**

If this iPad is signed into **Family Sharing**, this is required.

---

#### 4) **Check Downtime / App Limits (often the culprit)**
- **Settings → Screen Time**
  - **Downtime → OFF**
  - **App Limits → Remove all**
  - **Always Allowed → add needed apps**

---

#### 5) **Last resort (data-safe if you have iCloud backup)**
If it’s *completely locked* and you **don’t know the Screen Time passcode**:

- Back up via **iCloud**
- **Erase iPad**:  
  *Settings → General → Transfer or Reset iPad → Erase All Content*
- Restore from backup  
⚠️ Screen Time passcode **does not restore**, so this clears it.
