## Gmail App (iPhone or Android)

1. Tap search bar → type `from:owala`
2. Tap the **top checkbox** to select all visible
3. Scroll down, tap "Select all conversations that match"
4. Tap trash icon → done
5. Repeat: `from:halara`, `from:chase promotions`, etc.

**Pro move:** `from:owala` → three-dot menu → **Block "Owala"** + **Unsubscribe**. Kills it forever.

## Apple Mail (iPhone)

1. Open inbox → tap search → type "Owala"
2. Tap **Edit** (top right) → **Select All**
3. Tap **Trash**
4. Repeat per sender

Apple Mail is clunkier than Gmail for this. If you have heavy volume, I'd recommend using Gmail's web version on a laptop for 10 minutes — you'll clear months in one sitting.

## Outlook App
