# Primary Bureaus — Video Script Checklist

## WHY Video
- [ ] Why understanding the bureaus matters before applying for funding
- [ ] How bureau data directly determines approvals, limits, and terms
- [ ] Why most people treat bureaus as interchangeable (and why that's a mistake)
- [ ] The cost of ignorance — declined apps, wasted inquiries, lower limits
- [ ] Frame: "You can't optimize what you don't understand"

## WHAT Video
- [ ] Name and define all three: Experian, Equifax, TransUnion
- [ ] What each bureau actually is (data aggregators, not government agencies)
- [ ] What data each bureau collects (tradelines, inquiries, public records, personal info)
- [ ] Key differences between bureaus — which lenders pull which bureau(s)
- [ ] FICO score model variations across bureaus (EX = FICO 8, EQ = FICO 8, TU = FICO 8 — but lender-specific models vary)
- [ ] What a credit report actually contains (sections: personal info, accounts, inquiries, public records, collections)
- [ ] Difference between consumer reports vs. lender-pulled reports

## HOW Video
- [ ] How to pull your own reports (AnnualCreditReport.com, bureau direct, monitoring services)
- [ ] How to read and interpret each section of a report
- [ ] How to identify which bureau a specific lender pulls (database resources, community intel, soft pull pre-qual)
- [ ] How to use bureau knowledge strategically when sequencing applications
- [ ] How to freeze/unfreeze and when that matters for funding strategy
- [ ] How to monitor all three bureaus consistently (tools/apps to recommend)

## DO NOT Video
- [ ] Do NOT assume all three bureaus show the same data — they often differ
- [ ] Do NOT ignore discrepancies between bureaus (address mismatches, missing tradelines, score gaps)
- [ ] Do NOT apply without knowing which bureau the lender pulls
- [ ] Do NOT confuse VantageScore (Credit Karma) with FICO — lenders use FICO
- [ ] Do NOT neglect to check for mixed files, outdated info, or reporting errors before applying

## Action Item Video
- [ ] Pull all three reports today (free methods)
- [ ] Compare reports side by side — flag discrepancies
- [ ] Identify which bureau is strongest (highest score, cleanest profile)
- [ ] Note any errors, outdated items, or missing positive tradelines to dispute or add
- [ ] Begin mapping target lenders to bureau pull preferences
- [ ] Set up ongoing monitoring for all three
