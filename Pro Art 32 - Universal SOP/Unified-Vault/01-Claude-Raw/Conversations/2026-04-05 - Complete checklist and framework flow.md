# Complete checklist and framework flow

> [!info]- Conversation summary
> **Conversation Overview**
> 
> The person is building Video Sales Letters (VSLs) and asked Claude to create a comprehensive master checklist and framework flow based on two source materials: notes from a SCIO framework breakdown and a transcript from Alec Delpuech's guide on writing seven-figure VSLs. The first request produced a structured markdown checklist with verbatim quotes from both sources, organized into sequential phases (Open, Build, Close), covering all 10-11 VSL elements plus production rules, distribution tactics, and a pre-publish audit scorecard tied to Jordan Belfort's Three 10s trust framework (Trust in YOU, Trust in WAY, Trust for THEM).
> 
> The second request asked Claude to make the checklist visually appealing and optimized for ease, explicitly matching the aesthetic of a DSL comparison tool previously built together. Claude produced an interactive single-file HTML document with a dark premium UI featuring: a global progress bar tracking all checkboxes, a clickable phase flow timeline with color-coded sections, collapsible sections per VSL element, verbatim quotes visually differentiated by source (gold for SCIO, blue for Alec), AI briefs styled distinctly in purple, trust dial badges on every section, a guarantee type comparison table, and Expand All / Collapse All / Reset controls. The Alec transcript added elements not in the original SCIO framework, including the pillar-then-proof social proof loop within the Unique Mechanism section, a second Value Stack recap before the CTA, and a one-pager DM alternative for high-ticket offers.
> 
> The person's clear preference is for interactive HTML reference tools styled with a dark premium aesthetic — collapsible, scannable, and built for repeated use during production and auditing workflows rather than one-time reading.
